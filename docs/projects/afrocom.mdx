# 🌍 AfroCom

**The community layer of the Ubujima ecosystem.**

AfroCom is a community-driven platform designed to connect people, communities, creators, businesses and organizations across the global Afro-community.

It is the first major product being developed within the Ubujima ecosystem.

## Current Focus

AfroCom currently operates primarily as a community networking platform.

The current technology stack includes:

- 📱 **Flutter** — mobile applications
- 🌐 **React** — web applications
- ⚡ **Supabase** — current backend and API infrastructure
- 🖼️ **Cloudinary** — media storage and optimization
- ☁️ **Cloud infrastructure** — regional and scalable deployment

## Current Platform Capabilities

The platform is progressively developing capabilities including:

- 👥 Community networking
- 📝 Posts and content
- 💬 Chat and communication
- 📍 Location and map-based discovery
- 🏢 Business and organization profiles
- 📅 Events
- 💼 Jobs and opportunities
- 📣 Campaigns
- 🤝 Community co-creation
- 🎥 Rich media

## Current Development Priorities

Our immediate priority is to **stabilize and strengthen the existing community platform**.

Development includes:

- Improving existing features
- Enhancing UI and UX
- Improving performance and reliability
- Expanding communication capabilities
- Improving media handling
- Improving map and discovery experiences
- Automating content curation
- Increasing platform engagement
- Expanding web capabilities

## The Next Evolution

AfroCom is intended to evolve beyond community networking into a broader super-app ecosystem.

Longer-term areas include:

- 🛍️ Marketplace
- 💳 Fintech and digital wallet
- 🎬 Entertainment
- 🎮 Games
- 🎵 Music
- 🎥 Video and streaming
- 🤝 Crowdfunding
- 🧩 Co-creation
- 🛠️ Utilities
- 🤖 AI-powered services
- 🔗 Blockchain-enabled services

## Architecture Evolution

As AfroCom grows, we expect to progressively transition from the current Backend-as-a-Service architecture toward a more modular, internally controlled backend.

The long-term direction includes a service-oriented architecture capable of supporting the broader Ubujima ecosystem.

This transition will happen progressively rather than as a single rewrite.

**Build what is needed today. Architect for what comes next.**
