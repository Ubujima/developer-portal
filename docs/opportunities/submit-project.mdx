# Submit a Project

Have a technology project that could benefit from community collaboration?

Individuals, developers, startups, agencies, nonprofits, community organizations, and other partners may submit projects for consideration within the Ubujima developer ecosystem.

Selected projects may be featured through the Developer Hub and, where appropriate, connected with developers interested in contributing code, documentation, testing, research, design, or other technical support.

## What We Are Looking For

We are particularly interested in projects that:

- Solve meaningful problems
- Can benefit from collaboration
- Have a clearly defined purpose
- Provide useful opportunities for developers
- Align with responsible technology practices
- Have clear ownership and licensing arrangements

## Before a Project Is Featured

Ubujima may review:

- Project purpose
- Technical scope
- Repository status
- Licensing
- Intellectual property ownership
- Security considerations
- Contribution requirements
- Project leadership
- Community suitability

Submission does not guarantee acceptance, publication, development support, or inclusion within the Ubujima GitHub organization.
